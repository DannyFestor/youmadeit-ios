# You Made It — iOS

The native Swift client. Product docs, the voice guide, the glossary and the decisions that cross repos live in the parent repo, `youmadeit`, which holds this clone in its `ios/` folder.

## Voice

Every user-facing word follows the parent's voice guide, `docs/voice.md`: the companion doctrine, the never-pressure vocabulary, and the canonical moments table.

## Agent skills

### Issue tracker

Issues about the iOS client live as GitHub issues in this repo; product-wide and cross-repo issues live in the parent. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage labels use the default names: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

The glossary is the parent's `GLOSSARY.md`. Decisions inside the iOS client are in this repo's `docs/adr/`, numbered from 0200; decisions that cross repos are in the parent's. See `docs/agents/domain.md`.
